# Trotter Complete Race-Shape Key

Use this quick-reference key to decode Trotter's six-axis race-shape labels. For the reasoning questions and starting factor hypotheses behind each code, see the [full race-shape framework](./race-shape-framework.md).

> [!IMPORTANT]
> This is a classification and learning framework—not a finished betting system or a set of numeric factor weights. Trotter race shapes are also separate from DRF's own `C` and `S` pace symbols.

## Read the label from left to right

```text
CLASS-SURFACE/DISTANCE-PACE-EXPERIENCE-CONNECTIONS-VOLATILITY
```

Example:

```text
C1-DS-PU-E1-K1-V3
```

Plain English: a debut-heavy maiden special weight on dirt at a sprint distance; pace unknown; little comparable form; multiple prominent or high-rate barns; high volatility.

The code groups similar races for review. Always accompany it with a plain-English sentence explaining the actual reasoning.

## 1. Condition and class

| Code | Meaning |
|---|---|
| `C1` | Maiden special weight, debut-heavy |
| `C2` | Maiden special weight, exposed |
| `C3` | Maiden claiming |
| `C4` | Claiming, conditioned claiming, or starter |
| `C5` | Allowance, optional claiming, or non-winners condition |
| `C6` | Listed or ungraded stakes |
| `C7` | Grade III |
| `C8` | Grade II |
| `C9` | Grade I |
| `CX` | Other, restricted, or special condition |

## 2. Surface and distance

| Code | Meaning |
|---|---|
| `DS` | Dirt sprint |
| `DR` | Dirt route |
| `TS` | Turf sprint |
| `TR` | Turf route |
| `AW` | All-weather or synthetic |
| `OFF` | Wet/off main track or changed surface |
| `SDX` | Unclear or other setup |

## 3. Projected pace

| Code | Meaning |
|---|---|
| `P1` | Lone or controlling speed |
| `P2` | Contested speed or likely pace pressure |
| `P3` | Balanced or mixed pace |
| `P4` | Possible pace collapse favoring closers |
| `PU` | Pace unknown or insufficient evidence |

Derive pace from running lines and available pace evidence—not horse names or trainer reputation. Revisit the projection after scratches.

## 4. Experience and form

| Code | Meaning |
|---|---|
| `E1` | Debut-heavy; little comparable data |
| `E2` | Lightly raced; rapid improvement possible |
| `E3` | Exposed form; stable comparison set |
| `E4` | Mixed experience |
| `EU` | Missing or unreliable data |

## 5. Connection pattern

| Code | Meaning |
|---|---|
| `K1` | Multiple elite, recognizable, or high-rate barns |
| `K2` | One dominant connection versus mostly local or unknown rivals |
| `K3` | Mixed connections with no clear edge |
| `K4` | Primarily local, low-sample, or unknown connections |
| `KU` | Connection data unavailable |

Trainer recognition is a distinct signal. Keep it separate from measured meet/year performance, sample size, and race-specific trainer intent.

## 6. Volatility and confidence

| Code | Meaning |
|---|---|
| `V1` | Lower volatility: exposed, comparable form and a stable surface |
| `V2` | Moderate volatility: some important unknowns |
| `V3` | High volatility: firsters, surface changes, short samples, or chaotic pace |
| `VU` | Data too incomplete to classify confidently |

## Classification checklist

Before ranking contenders:

1. Select exactly one code from each axis.
2. Preserve unknowns with `PU`, `EU`, `KU`, or `VU` rather than guessing.
3. Write a plain-English interpretation of the six-code label.
4. State which factors should be primary, supporting, contradictory, or low-information for that shape.
5. Reclassify after material scratches or a surface change.
6. Preserve the pre-race shape after results; record predicted and observed pace separately when they differ.
